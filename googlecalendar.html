⚠️ Setup Required: Google Calendar Configuration

Before using this calendar, you need to configure the Google API credentials. Follow these steps:

  1. Go to Google Cloud Console: https://console.cloud.google.com/apis/credentials
  2. Find your OAuth 2.0 Client ID (created for this calendar)
  3. Click Edit (pencil icon)
  4. Add Authorized Redirect URIs:
    • For local testing: http://localhost:8000
    • For GitHub Pages: https://eulagitpro.github.io
  5. Click Save
  6. Refresh this page and try signing in again

Important: The redirect URIs in Google Cloud Console must exactly match where you're accessing this calendar from.
